# federation-gods-eye

The NextXus Federation from above: every live domain and its purpose, the Three Minds, and the three architecture layers, in one plain-HTML briefing.

This is the Cosmological Observation Room — not a dashboard, a room you enter to observe. The world-monitor layer streams live RSS intelligence, the Federation node layer maps every site and SIM, and an embedded AI panel reasons alongside the observer. Written for visitors who need the whole picture at once, and for AIs that need machine-readable orientation to the Federation.

## What's inside

- `index.html` — the observation chamber: live domains, the Three Minds, architecture layers
- `VISION.md` — the vision document: what the chamber is, what it is becoming (World Monitor, node layer, inter-layer navigation, Mirror Procedure)
- `BUILD-NOTES.md` — build notes and construction record
- `panels/sim.html` — a simulation panel view
- `previous-edition.html` — the prior edition, kept for the record

## Principle

Plain HTML first. No build step, no framework — the page reads the same to a browser, a crawler, and an AI.
